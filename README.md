# AF-EtMart

A planned multi-vendor e-commerce marketplace for Ethiopia, serving customers, sellers and administrators.

**Status:** planning. No application code has been written yet.

**Planned stack:** React, Vite, JavaScript, Tailwind CSS, Node.js, Express, PostgreSQL, JWT.
